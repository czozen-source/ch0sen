# Rejestr uszkodzeń wózków

Aplikacja (claude.ai Artifact) do rejestrowania uszkodzeń wózków widłowych na magazynie.

- Opublikowana wersja: https://claude.ai/artifact/T5NeW2mYmGDgZ7SQS5JqzZ
- Źródło: `index.html` (publikowane z capabilities `db` + `user`).

Kolekcje w bazie: `forklifts`, `employees`, `impacts` (rodzaje uderzeń), `damages` (zgłoszenia).
Statusy zgłoszeń: Zgłoszona → W naprawie / Czeka na części → Naprawiona / Bez naprawy.
